# Math Fighters

Juego educativo de combate por turnos hecho en Unity (2D). Eliges un equipo de personajes y te enfrentas a dragones; para atacar tienes que responder correctamente operaciones matemáticas.

**Autores:** Victor Mendoza y equipo (2024)

## Cómo se juega

- Escoge tus personajes y entra al combate.
- En tu turno, elige un movimiento y responde la operación matemática para que tenga efecto.
- Cada personaje tiene un elemento; algunos ataques son muy efectivos y otros poco efectivos según el rival.
- Hay movimientos de daño, de modificación de estadísticas (ataque, defensa, velocidad) y mixtos.
- Si un personaje cae, puedes cambiarlo por otro del equipo.
- Gana monedas y vence a todos los dragones para terminar el juego.

## Cómo jugarlo (Windows)

1. Descarga `MathFighters-Windows.zip`.
2. Descomprímelo.
3. Abre `Math Fighters.exe`.

## Tecnologías

- Unity 2D (Animation, IK, Tilemap, Pixel Perfect)
- C#
- Guardado de partida en JSON
